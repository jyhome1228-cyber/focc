# Heroes of Korea — FOCC website concept

첨부 레퍼런스를 바탕으로 제작한 **정적 반응형 홈페이지 1차 시안**입니다.

## 구성
- 3단 중앙 로고 헤더 및 모바일 메뉴
- 큰 Heroes 타이포 / 에디토리얼 그리드
- Archived in Scent 제품 영역 (CSS 목업 이미지: 실제 상품 사진 아님)
- 브랜드 스토리 / 저널 / 사업자정보 푸터
- GitHub Pages에서 시안 확인 가능

## 중요
- 카페24 쇼핑몰과 GitHub Pages는 **별개**입니다. 이 저장소를 업데이트해도 카페24 실사이트에 자동 반영되지 않습니다.
- 상품 카드 및 메뉴 링크는 시연용이며 카페24 상품 데이터, 로그인, 장바구니, 결제, 회원 기능은 아직 연동되지 않았습니다.
- 상단 계정 링크, 결제 정보, SNS 링크 등은 최종 연결 전 임시 표시입니다.
- 푸터 사업자 정보는 전달된 스크린샷 기준이므로 실제 등록정보와 대조해 주세요.
- 이후 카페24 적용 시 /layout/basic/header.html, /layout/basic/footer.html, index.html, CSS 파일로 분리하고 카페24 모듈을 유지해야 합니다.

## 미리보기
GitHub 저장소 Settings > Pages에서 main / (root)를 배포 소스로 선택하세요.
